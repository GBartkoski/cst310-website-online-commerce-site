# Online Shop

## Project Overview
This project is an online shop that allows users to browse products, filter them by category, and add items to their shopping cart. The application is built using HTML, CSS, and JavaScript.

## Files Overview

- **index.html**: Contains the HTML structure for the online shop, including a badge for the cart item count, category filter buttons, and a container for product cards.

- **app.js**: Contains the JavaScript logic for managing products and the shopping cart. It includes functions to add products to the cart, view cart contents, filter products by category, and dynamically render product cards.

- **styles.css**: Contains styles for the HTML elements, including layout and design for product cards, category filters, and the cart badge.

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd js-online-shop
   ```

2. **Open the Project**
   Open `index.html` in your web browser to view the online shop.

3. **Usage**
   - Browse through the available products.
   - Use the category filter buttons to filter products by their respective categories.
   - Click on the "Add to Cart" button on each product card to add items to your cart.
   - The cart badge will display the number of items currently in your cart.

## Features
- Dynamic rendering of product cards based on available products.
- Category filtering to easily find products.
- Real-time cart updates with a badge indicating the number of items in the cart.
